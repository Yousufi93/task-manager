# Task Manager

A simple command-Iikne task manager bulit with Python.

## Feature 
- Add tasks
- Show all tasks with their status
- Mark tasks as done
- Delete tasks
- Save tasks to a file (so they are not lost when the program closes)

## How to run

python mains.py
